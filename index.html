Engine 01 · Master's thesis

Edge–Cloud LLM Inference

A multimodal LLM inference system with speculative decoding between NVIDIA Jetson and a GPU server.

31.8–48.3 % less target-server time than autoregressive decoding

  • Python
  • PyTorch
  • gRPC
  • Jetson

02/2026 — 09/2026

Edge–Cloud Speculative Decoding for Multimodal LLMs. An asynchronous gRPC front end is decoupled from a separate GPU inference process via request/response queues and pending-request matching.

Evaluated with LLaVA-1.6 7B and Qwen2.5-VL 7B on Jetson and H100: in the single-request configurations studied, the system needed 31.8–48.3 % less target-server execution time than server-side autoregressive decoding. A compact interface reduced the one-time prefill response by a factor of 14.08–37.61 compared with the earlier interface.

Engine 03 · Personal project

Raspberry Pi Ball Tracking

Detects and automatically tracks a ball with OpenCV, I²C motor control and a live browser preview.

  • C++17
  • OpenCV
  • WebRTC
  • CMake
GitHub

Modular C++17 application that detects a ball with OpenCV and tracks it automatically via PCA9685 over I²C. GStreamer/WebRTC provides the live preview.

Separate processing and streaming threads use a latest-frame strategy. CMake supports cross-compilation for AArch64, reproducible offline replays and a CTest for I²C error paths.

Engine 04 · University project

STM32 Interfaces & Oscilloscope

Embedded C projects for sensor interfaces, a traffic-light controller and an ADC oscilloscope with LCD waveform display.

  • Embedded C
  • STM32
  • SPI / I²C
  • ADC
GitHub

Developed on the NUCLEO-L053R8: SPI communication with an ADXL345 accelerometer, software I²C for a QMC5883L magnetometer, One-Wire for a DS18B20 temperature sensor, and UART readout.

A table-driven finite-state machine controls the traffic-light project. The oscilloscope uses timer-driven ADC sampling, a 240-sample circular buffer and falling-edge triggering, with waveform display and button-controlled zoom on an ILI9341 LCD.
